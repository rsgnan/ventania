# Ventania

Sistema de gestão de estoque e vendas desenvolvido com Laravel.

> 🚧 **Projeto em desenvolvimento**

O Ventania está sendo desenvolvido para oferecer uma solução simples para gerenciamento de produtos, estoque e vendas.

## Funcionalidades

- Cadastro e gerenciamento de produtos
- Categorias de produtos
- Controle de estoque
- Busca e filtro de produtos
- Paginação da lista de produtos
- Edição e remoção de produtos
- Funcionalidades de vendas

## Tecnologias

- Laravel
- PHP
- Blade
- Tailwind CSS

## Projeto

O Ventania possui uma interface simples e objetiva para facilitar o gerenciamento de produtos, estoque e vendas.
