# Ventania

Sistema de gestão de estoque e vendas que estou desenvolvendo em PHP.

O projeto começou como um controle simples de estoque e aos poucos estou adicionando novas funcionalidades.

## Funcionalidades

- Dashboard
- Cadastro de produtos e categorias
- Controle de estoque
- Cadastro e edição de vendas
- Controle de status das vendas
- Cadastro de usuários
- Registro de atividades

## Tecnologias

- PHP
- MariaDB
- HTML
- CSS
- JavaScript

## Sobre o projeto

O Ventania utiliza uma estrutura MVC própria, feita em PHP puro, sem frameworks.

Atualmente estou trabalhando na parte de estoque e vendas locais. A ideia é futuramente adicionar novos módulos e integrações com marketplaces.
